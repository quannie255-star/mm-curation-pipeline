## 2. 结果（核心数字）

```
index            n     R@1     R@5    R@10     MRR
clean_v2      1585   0.556   0.824   0.901   0.670
dirty_raw     1585   0.459   0.791   0.874   0.599
```

**结论（可直接进 README/简历）**：在同一个查询集与同一 ground truth 下，
清洗使 **Recall@1 从 0.459 → 0.556（相对提升 21%）**，MRR 从 0.599 → 0.670（+7.1pp），
Recall@10 从 0.874 → 0.901。污染伤害集中在头部名次（R@1 掉幅 9.7pp vs R@10 2.7pp）。

## 3. 查询来源分列（自检索偏置检验）

| 查询类型 | n | clean R@1 | dirty R@1 | 退化 |
|---|---|---|---|---|
| held_out（未参与索引构建的 caption） | 119 | 0.580 | 0.487 | -9.3pp |
| self（入库 caption 自检索） | 1466 | 0.554 | 0.457 | -9.7pp |

两类查询退化幅度一致 → 自检索的乐观偏置没有扭曲对比结论；
held_out 的绝对值略高（更自然的查询文本反而检索更好）。
