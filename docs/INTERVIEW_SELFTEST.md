# 面试自测题库：把项目从「能讲」变成「能扛追问」

> 用法：**遮住答案要点，只看问题作答**，答完对照。答不上来 → 回答案锚点重读。
> 判分标准：能说出关键数字 = 及格；能说出数字怎么来的 = 良好；能说出「如果重做会怎么改」= 面试安全。
> 建议节奏：投递前自测三遍，间隔 ≥2 天；每遍只标记「卡壳题」，下一遍只刷卡壳题。

## L1 数字层（15 题）——每个简历数字都要能脱口而出

1. **漏斗的输入输出是多少？**
   要点：2106 → 1586 存活 / 1585 入索引；脏数据召回 99.8%（485/486）、干净误杀 2.16%（35/1620）。
   锚点：INTERVIEW §六数字表；README 核心结果表。
   ⚠️ 高频坑：Demo 页显示 99.8%，旧文档曾写 100%——必须知道为什么（见 L2 第 5 题）。

2. **清洗收益的检索指标？**
   要点：R@1 0.459→0.556（+21%）、MRR 0.599→0.670、R@10 0.874→0.901；脏索引 vs 净索引对比。
   锚点：INTERVIEW §二 STAR / README 核心结果表。

3. **配比实验数字？**
   要点：分层 vs 随机采样（budget=1000）R@1 0.353→0.437（+24%）。

4. **消融归因结论？**
   要点：分组消融中**去重组是唯一显著组**（ΔR@1=-0.017）——「收益主要来自去重」这句话的出处。

5. **算子级评测两个代表数字？**
   要点：phash_near 主靶 recall 84%/误杀 0.24%；clip_alignment 主靶 recall 96%/误杀 0.19%。
   ⚠️ 口径坑：算子评测是「独立评测口径，非漏斗串联」——漏斗里算子串联，独立评测里每个算子单独对全集打分。

6. **Phase 2 自训检测器？**
   要点：防「循环论证」（用自己的检测器评自己）→ 训独立检测器，testB 泛化 87.3%/主靶召回 100%/误杀 0.8%。

7. **Phase 2 训练级证据？**
   要点：CLIP 微调 clean_ft vs dirty_ft R@1 0.688 vs 0.636（差 5.2pp）——「代理指标升级为训练证据」。

8. **文本侧去重基准？**
   要点：10 万档 exact 1.0 / near 0.9714 / 21.1s；30 万档 60.4s（近线性）。

9. **文本侧训练级证据？**
   要点：GPT-2 zh held-out ppl 7.16 vs 7.70（脏语料 +7.5%，超 5% 验收线）——第二个模态的同构证明。

10. **文本全量漏斗？**
    要点：30.2 万篇中文维基，302,002 → 181,980（保留率 60.3%）。

11. **V3 ζ 的核心数字？**
    要点：通用 κ=-0.024 → LoRA 微调 κ=+0.560（P=0.706 / R=0.960 / 解析率 100%，验收线 ≥0.5）。
    ⚠️ 必须能解释 κ 是什么（cohen's kappa，一致性系数，修正随机一致）以及为什么用 κ 不用 accuracy（类别不平衡下 accuracy 会骗人）。

12. **benchmark 规模与防污染设计？**
    要点：judge_news_v1，300 条（clean 150 / dirty 150），版本冻结入库；train/benchmark seed 隔离 + md5/MinHash 双重防泄漏检查。

13. **测试与工程基线？**
    要点：主仓 157 + 包 40；双 CI 徽章；59 条工程笔记；三层门禁（代码逻辑 → 单点质量数字 → 整条阈值曲线）。

14. **检索服务的生产化数字？**
    要点：实时质量门 POST /api/ingest（质量评分 + 三层增量判重 + accept 一次返回）；跨集去污染召回 94.4%；PSI 漂移换源批 0.36-0.66 告警。

15. **阈值回归门守的是什么？**
    要点：threshold_scan 曲线对冻结基线逐点比对（recall 偏移 >0.05 / 误杀偏移 >0.02 即红）——防 imagehash/datasketch 换库版本静默漂移；单测绿、单点门禁过、曲线先变。

## L2 根因层（8 题）——失败故事的细节决定可信度

1. **δ 阴性：通用 0.5B 判官为什么 κ≈0？这个「失败」值在哪？**
   要点：诚实阴性（κ≈0.013/-0.024）→ 原样写进 README → 成为 V3 立项依据。话术：「数字不达标不等于没价值，藏着才算失败」。
   锚点：INTERVIEW §七 δ 段 / §八开头。

2. **ζ 三次训练的根因链？（必考）**
   要点：v1 κ=-0.18 协议错位（裸 prompt 训练、模板 prompt 考试）→ v2 κ=-0.007 completion 窗外截断（loss 正常但任务被静默替换）→ v3 +0.560。
   金句：「loss 是模型在学『某个』任务的证明，不是在学『你要的』任务的证明」。
   锚点：INTERVIEW §八「三次训练的根因链」；工程笔记 #58/#59。

3. **phash 合成测试图两连败？**
   要点：噪声图低频无信息、单频光栅能量集中单 bin，两两距离都塌缩 → 终版 8×8 随机块拼图 + 测试内自校验种子（两两距离 ≥16 才用）。教训：给感知算法造测试数据前先读它的特征提取代码。
   锚点：工程笔记 #57。

4. **ε 门禁为什么先标定生成器再定门限？**
   要点：否则门禁测的是生成器不是算子。图像门禁裁剪强度三收窄（4~10% → 1~5%）：块状合成图对裁剪比真实照片敏感（裁剪移动 8px 块网格）。第二次按此方法论走（ε2）就一次到位。

5. **为什么现在写 99.8% 而旧版写过 100%？（口径题，答对是加分项）**
   要点：README 承诺「所有数字可一键复现」——当前仓库实跑产物是 485/486（漏 1 条 nsfw_placeholder 类），旧批次 100% 已被覆盖、不可复现，所以活文档对齐可复现口径，历史日志（ROADMAP 2026-08-22）保留当时事实。漏的那 1 条恰好在索引构建时图片缺失又被滤掉（1586 存活 → 1585 入索引）。
   话术：「我们不用旧批次的漂亮数字，两个『不完美』都如实写。」

6. **Data CI 曾连红三次，根因和教训？**
   要点：图像门禁脚本漏插 curation-eval 源码路径，本地 editable 安装掩盖，CI 裸环境 import 即崩。教训：门禁脚本必须假设裸环境；「本地绿 ≠ CI 绿」。
   锚点：工程笔记 / RUNBOOK。

7. **git push 挂死的三层根因？**
   要点：system 层 helper-selector 取不到凭据 → 回退终端交互询问 → stdin 阻塞；`-c credential.helper=X` 是追加不是替换。一秒判别：`git ls-remote` 秒回 = 网络正常。
   锚点：工程笔记 #56 / RUNBOOK §0.1。

8. **中文 CLIP 接入时的三个环境坑？**
   要点：transformers 5.x 强制 torch≥2.6 → 降 4.57；官方只有 .bin（CVE 限制 torch.load）→ 本地转 safetensors；4.57 中文文本塔回归（pooler_output=None）→ 按官方实现取 CLS+projection。
   锚点：ROADMAP 2026-08-22 日志。

## L3 设计取舍层（11 题）——「为什么这么设计」

1. **为什么 κ 而不是 accuracy/F1？** 类别不平衡下 accuracy 骗人；κ 修正随机一致；且 δ→ζ 用同一把尺子才可比（通用 -0.024 vs 微调 +0.560）。
2. **为什么 0.5B 而不是 7B？** 本机 8GB 约束；立项时用 L1 规则 κ=0.565 论证「任务信号充足，0.5B 学得动」——事后被 +0.560 与 0.565 几乎打平验证。
3. **为什么 LoRA 而不是全参微调？** 8GB 显存、防灾难性遗忘、适配器可插拔（=数据资产不绑定基座）。
4. **为什么 benchmark 要版本冻结 + seed 隔离？** 训练数据与评测数据同源会泄漏；冻结才能跨实验可比（v1/v2/v3 三次训练同一把尺）。
5. **为什么 MinHash-LSH 参数是 80 perm / 8 band？** 权衡召回/误杀/吞吐；阈值扫描曲线显示拐点位置（见 threshold_scan 报告）。
6. **为什么自研 curation-eval 包而不是用 Data-Juicer？** Data-Juicer 提供算子，不回答「算子好不好」；协议层收口后主仓反向消费——「自己产品的第一个用户」是可复用性最硬的证明。
7. **为什么漏斗是 11 级串联而不是一个大模型打分？** 规则层便宜可解释、感知层渐进贵；每级 P/R 可独立归因（消融实验证明去重组贡献最大）。
8. **为什么双运行时（local/Ray）要求四口径等价？** 单机可复现 + 分布式可扩缩，等价性验收（kept 集/StageStat/逐 id 分数/dedup 标记）保证切换无语义漂移。
9. **为什么簇代表取字典序最小 id？** 执行前按 id 排序 → 代表确定性，分布式下结果可复现。
10. **为什么检索用 IndexFlatIP 而不是 IVF/HNSW？** 千级规模精确检索零损失；规模 ×100 才需要 ANN（可顺势接 L4 第 1 题）。
11. **偏好闭环（η-a）为什么把「偏好」操作化为「详略」维度，还要 persona-oracle？** 「偏好」太泛没法造 ground truth；详略（PA 精炼派 vs PB 求全派）是可程序化构造变体对（S/F）的维度；persona-oracle（标注者=构造协议本身，非真人）如实声明，且用候选顺序随机化 + 内容对照题防「选长的」长度 shortcut。验收用**双判官分歧率 ≥40%** 而不是单判官高分——偏好的本质是「人和人不一样」，全都答对反而说明学成了客观题。

## L4 拆现场层（9 题）——「换个场景还成立吗」

1. **数据量 ×100 怎么办？** 索引换 ANN（IVF/HNSW）+ 分片；MinHash 已向量化近线性（30 万档实测）；Ray 执行层已验收等价 → 水平扩 worker；CLIP 编码是瓶颈 → 批处理 + GPU 集群。成本核算有四维 cost_model。
2. **不用 CLIP 换多语种/新模态怎么办？** 协议层模态可插拔（V2 β 已证明文本零特例接入）；编码器是算子的可替换依赖。
3. **ζ 的判官换到我的数据域要多久？** 四步闭环（fetch → build benchmark → LoRA → eval）；瓶颈在 benchmark 构建质量而非训练（训练 70 分钟）；seed 隔离/防污染流程直接复用。
4. **如果 ζ 训出来只有 0.2 怎么办？** 如实报告 + 保留规则方案兜底（L1 规则 κ=0.565 是现成 fallback）——「诚实比漂亮重要」。
5. **脏数据类型变了（新水印样式）怎么办？** 三层防线：阈值回归门抓库漂移、数据门禁抓召回劣化、污染器可加新损伤类型重新标定。
6. **这项目几个人做的？**（诚实协作题）说清分工与 code review 流程，强调协议层/文档口径/评测闭环是自己主导；**面试前务必精读协作方代码**（finetune_judge_lora.py、benchmark builder）——面试官不知道分工存在。
7. **最遗憾/下一步？** PRD 三条愿景差距已书面化（PRD §九）：偏好闭环（η-a 在途：详略维度 DPO）、域外泛化（η-c 在途：wiki OOD benchmark 补验收 4 欠账）、产品化入口（有意裁剪，Web UI 在 Out 清单）；第二任务（η-b）视 η-a 结果立项。
8. **你的贡献用一句话？** 「我把『数据清洗』做成了『可证明、可复现、可归因的质量工程』——每个数字有实验、每个实验有门禁、每个失败有根因。」
9. **「这平台真能让人按自己偏好训模型吗？」（必戳的愿景差距题）** 不嘴硬：首战锚点（判官 κ 达标）只是底盘，偏好闭环当时不存在——但差距不是被问出来才承认的，是**自己先写进 PRD §九**，再按差距立项 η（η-a 偏好 DPO + η-c 泛化补账在途）。要点：δ 阴性→V3 立项、ζ 达标→η 立项，是同一个「让数字/差距驱动下一步」的叙事基因；「先交付可验证的底盘，差距书面化，按差距立项」= 产品判断力。
   锚点：PRD §九、docs/design_tables.md η 设计门（0e9795d）。
