## 版本 A · 通用版（4 条，不确定方向就投这版）

- 独立设计并实现面向大模型训练数据的端到端质量平台（Python / Airflow / FAISS / Ray / Streamlit）。核心方法是用**程序化污染器**向干净种子集注入带标注的脏数据（注入即复制、原始样本不动、每类脏数据对应一个主靶算子），把"真实脏数据没有标准答案"这个行业痛点转成可算 precision/recall 的评测协议。
- 构建 11 级清洗漏斗（L1 规则 → md5/pHash/MinHash-LSH/语义去重四件套 → Chinese-CLIP 图文对齐），算力分级（CPU 规则算子先行缩小规模，GPU 编码最后跑）；脏数据召回 99.8% / 误杀 2.16%；用清洗前后双索引对比证明收益——**Recall@1 0.459 → 0.556（相对 +21%）**，并量化"头部挤压"效应（R@1 退化 9.7pp 而 R@10 仅 2.7pp）。
- 把结论从代理指标推到训练级证据：同架构同超参同训练量下，CLIP 干净集微调 R@1 **0.688 vs 脏集 0.636**，中文语料 GPT-2 困惑度 **7.16 vs 7.70（+7.5%，超 5% 验收线）**——"脏数据伤模型"在图像与文本两个模态独立复现，测试集与训练集代码级不相交。
- **主动补因果对照，回应"提升是不是只是因为删了样本"**：实现随机删同比例 baseline（10 seeds）+ 脏残留剂量对照，证明漏斗的 R@1 提升来自"删对坏样本"而不是"库变小"（随机删同数量后 R@1 反而从 0.575 降到 0.447，清洗净贡献 **+0.13**）；全部引用数字注册进 `claims.json` 并由校验脚本逐条锁定（漂移即 exit 1）。

## 版本 B · 框架 / 平台方向（3 条）

- **零特例协议抽象**：把协议与算子 SDK 抽炼为可 pip 安装的独立包 `curation-eval`（Sample 协议 / 模态登记 / 算子注册表元数据 / Executor 抽象 / 污染器框架五件），原管道反向消费该包——"可复用"由自己当第一个用户来证明；据此接入第二模态（30.2 万篇中文维基，8 级文本漏斗，保留 60.3%）时**未新增任何框架特例**。
- 自研向量化 MinHash-LSH，把 30 万文档签名去重从小时级压到 60s（10 万档 exact 1.0 / near 0.9714 / 21.1s，近线性扩展）；实现可替换执行层（local / Ray 双运行时），同一 YAML 算子图改一行 `runtime: ray`，10 万～100 万档三口径等价性**逐 id 零差异**（含簇代表标记），并如实报告"Ray 在单机全区间无回本点、回本条件是多机横向扩展"的适用边界。
- **把平台形态固化为规范**：定义「基座 + 领域增强包六件套（模态适配器 / 领域算子 / 领域污染器 / 确定性合成语料 / 漏斗 config / 评测门禁）」，据此零特例接入医疗 FHIR（第三模态，500 条合成 R4，PHI/编码/单位/时间/引用五算子）与工业传感器（第四模态，1056 窗时序，卡死/量程/漂移/单位/计划检修五算子），**框架层 0 diff**（sdk/registry/runner 无变更）；门禁按 3 seeds 最差口径保守聚合：医疗召回 100% / 误杀 0.00%（分母 0/500）、工业 100% / 1.23%（分母 13/1056，实绩 1.04%），分母与 seed 稳定性一并入报告。

## 版本 C · 微调 / 评测方向（3 条）

- 设计并落地「自己的数据 → 自己的 benchmark → 自己的模型」三步闭环：自研 benchmark 构建器（300 条版本冻结评测集 + train/eval seed 隔离 + md5/MinHash 双重防污染 + SFT 结构性排除），LoRA 微调（peft + Qwen2.5-0.5B，本机 8GB 单卡）把域专属判官的 Cohen's κ 从 **-0.024 提到 +0.560**（P 0.706 / R 0.960 / 解析率 100%，验收线 ≥0.5）；两次阴性训练的根因链（协议错位 → completion 窗外截断）完整落档为工程笔记。
- 偏好闭环：用 DPO（trl + peft + 最小对纪律）把"主观口味"训成判官，双 persona 判官命中率 **0.933 / 0.867**、双判官分歧率 **0.783**（验收线 ≥0.75 / ≥40%）；再做成非开发者可用的五步向导（Streamlit：导入 → 标注 → 训练 → 评测 → 试用），冻结考卷 77 题两轮不动，通用 **0.532 → 个人判官 0.839（+30.6pp）**，并用"加量不换考卷"的学习曲线把"最少标注量约 500 对"变成有实验支撑的产品参数。
- 判官能力矩阵 + 成本核算：实测 0.5B / 1.5B 两档在四个域任务上的能力悬崖（通用模型放大不保证单调，域任务仍只有微调能救），给出本机自训判官 vs 商用 API vs 人工标注的成本差（约 235× / 23000×），把"要不要自训判官"从技术判断变成数据决策。

## 版本 D · 数据工程 / 数据治理方向（3 条）

- 搭建独立于代码 CI 的**数据 CI**（GitHub Actions 第二流水线）：合成标注语料真跑去重算子（文本门 0.5s / 图像门 40s，exact 1.0 / near 0.994 / 误杀 0），外加整条**阈值曲线回归门**（MinHash/pHash 曲线逐点比对冻结基线，13s，召回偏移 >0.05 或误杀偏移 >0.02 即红）；三层保护（代码逻辑 → 单点质量数字 → 阈值曲线）使"换库版本 / 换数据源导致的静默漂移"可被捕获；并用"人为把算子调坏 → 门禁必须变红"的劣化注入实测（exit 1）证明门禁真的会红，而不是永远绿。
- 建"运维飞轮"日跑链路（真实线上数据：采集 → 巡检 → 清洗 → 日报 + 驾驶舱，失败仍出日报、单源失败不阻塞、非零即停）：首日审计即抓到 46 条域误杀（阈值与金融域不匹配，抽样全是数字密集行情快报），进 backlog 做阈值校准——验证"门禁 + 审计飞轮"在真实分布上的价值，也印证合成语料的已知边界。
- 新增 **dbt 数仓建模模块**（`warehouses/`，dbt-duckdb）：把平台轨的湖 / 契约 / 台账落成星型模型（`dim_*` / `dws_*`），配 5 条 SQL 断言（SCD2 完整性 / SCD2 与平台一致 / 漏斗无时间维 / 比率在单位范围 / 时序表含日期）+ `scripts/dbt_gate.py` 门禁；生成物不入库，`profiles.yml` 只有相对路径、无凭据，clone 下来即可跑。

## 版本 E · AI 数据生产 / Agent 编排（2026-10 升级，**最新**）

- **把「洗过的文本」升级成「可直接训练的数据集制品」**：`清洗 JSONL → tokenize → md5+MinHash 双检泄漏 → 定长 block packing → Parquet(ZSTD) + manifest`。实测产出 `news_zh_v2`：**1929 样本 / 167 万 token / 1182 定长 block(512)**，padding 仅 1.452%、泄漏 0 对；产物用 `datasets.load_dataset` + `DataLoader` **零适配**读通，真训 300 步 val loss **11.97 → 6.45**（跨过随机基线 ln(151665)=11.93）。manifest 是唯一真相源（规模 / 谱系 / 切分 / 校验和 / 训练结果全部实测写入，无占位）。
- **清洗到底值不值：配对对照的严格口径**。两臂共用**臂外** held-out（207 block）+ **同一批 seed** 做配对，判据用**配对符号检验**（先否掉了 max−min「噪声地板」版——实测 Δ/地板 = 1.009 是假阳性）：8 个 seed **全同号**，Δ = +0.0214，p = **0.0078**。两处边界如实标注：Cohen dz = 2.12 **不代表效应大**（差值仅 0.02 量级）；两臂样本数不同（1929 vs 1960），「唯一变量只有清洗」字面不成立。
- **Agent 编排只省成本、不掉质量**：4 档代价漏斗（rule/perceptual/model/llm）加自适应路由，LLM 判官调用 **293 → 6**，成本**省 64.44%**，而保留率 **97.67% 逐位持平**、污染臂 **0 漏检**；跳档白名单**代码强制**（实测 MODEL 档独拦 118/120 条乱码 → 不许跳）。变异测试 **6/6**。
- **数据合成与增强**（`src/mm_curation/synthesis/`）：计划级 1→N，6 种手段（3 文本 + 3 图像），带 `synthesized_by`/`source_id`/`clean` 溯源三元组，运行时断言**绝不带 dirty 标记**，「什么都没改」的样本会被丢弃。**三臂同口径对照**（同一条漏斗、同一阈值）：真实干净 1.83% / 合成增强 1.27% / 污染注入 43.67%（≈ **24×** 背景），判据是三条关系而非三个数字；变异 3/3。核心边界：**增强 ≠ 逆向还原**（`text[:3]` 截断类污染不可逆，声称能修 = 编造内容）。
- **给非开发者的 Web 前端（Studio）**：`python scripts/run_studio.py` → 上传自己的数据 → 选业务场景 → 得到可训练数据集，全程零代码。底层与命令行链路**完全同一套漏斗 + 同一个 DatasetBuilder**，没另写清洗逻辑；四场景配方逐条对齐真实跑通的配置，并主动标注每个场景**已知会误伤的地方**。
- **门禁从「文档一致」推到「结论可信」**：`.github/workflows/gate-ci.yml` 一次 CI 同时验「数字没漂」与「门禁本身还能拦红」（`verify_claims.py` + 5 个变异 + 3 个静态门禁：绝对路径 / YAML 粘连 / 编码卫生）。顺带修掉一个**假绿**：`verify_claims.py` 原先把 `missing`/`pointer-broken` 只打进汇总行、不计入红项 → CI 干净检出时 16 条 claim 全失效却报绿；已加 `--reports-missing {fail,skip}`。

## 诚实边界（主动讲是加分项，被问出来是减分项）

1. 医疗 / 工业门禁数字全部来自确定性合成语料，**真实分布泛化未验证**（验证计划在案：Synthea → 真实院内；工业核心判别"计划检修 vs 链路故障"需带检修台账的数据集）。
2. 微调级实验单 seed、无训练方差估计；held_out 查询 119 条，±1pp 波动属正常。
3. 去重组 ΔR@1 -0.017 是历史数字（分组口径结果未落盘），已在 claims.json 标 `historical`，引用必须注明。
4. 规模结论停留在 100 万档实测，"100 倍以上"是推演不是实测。
5. 对抗注入 / 未知脏类型 / 多语言 / 长尾公平性未覆盖。
6. 门限（90% / 5%）是**回归红线不是质量目标**，故意与实绩留出劣化检测带。
7. 训练数据生产：清洗 vs 未清洗的对照**只丢弃 1.6%**（25 条转载重复）→ **只说明「这批数据」清洗有效，不是「清洗一般有效」**；且两臂样本数不同（1929 vs 1960）。数据合成只覆盖纯文本 + L1 规则层（6 算子），未接 L2 感知层（口径选择，非能力缺口）。
